# El jardín de Jenny · Versión simple

Abrí `index.html` con doble clic. No requiere instalación ni servidor.

Solo hay un archivo de código y las imágenes. Los tres mensajes, la fecha y las fotos del carrusel se editan al final del HTML. Incluye 22 imágenes, contador de días, tres flores con mensajes, carta corta y persistencia local cuando el navegador la permite. Las escenas de boda se presentan como sueños.

Web: https://salvatury.github.io/el-jardin-de-jenny/
