# El jardín de Jenny · Versión simple

Abrí `index.html` con doble clic. No requiere instalación ni servidor.

Solo hay un archivo de código y las imágenes. Los tres mensajes, la fecha y las fotos del carrusel se editan al final del HTML. Incluye doce imágenes sin repetir, contador de días, tres flores con mensajes, carta corta y persistencia local cuando el navegador la permite. Las escenas ilustradas se distinguen de las fotografías; la imagen de boda se presenta como un sueño.

Web: https://salvatury.github.io/el-jardin-de-jenny/
