# El jardín de Jenny · Versión simple

Abrí `index.html` con doble clic. No requiere instalación ni servidor.

Solo hay un archivo de código y la imagen `nuestro-viaje.jpg`. Los tres mensajes y la fecha se editan al final del HTML. Incluye contador de días, tres flores con mensajes, carta corta y persistencia local cuando el navegador la permite.

Web: https://salvatury.github.io/el-jardin-de-jenny/
